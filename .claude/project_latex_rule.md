**Why:** Project structure requirement with zero flexibility.

**How to apply:** Every notebook conversion to LaTeX, PDF generation, or new report file must be saved to the Weekly Report folder. Check for existence first; create folder if needed. Never save LaTeX/reports to project root or other locations.
